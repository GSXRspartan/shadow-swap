# Multi-hop invariants — XTM → FAST_XTM_TARI → TARI → AMM

Complements `security/CROSS_LAYER_INVARIANTS.md` (the hop-1 invariants still apply and are
not restated). Every invariant names the code that enforces it and the test that proves it.
`MH` = `test/multihop_hostile.test.cjs`, `MF` = `test/multihop_fuzz.test.cjs`.

| ID | Invariant | Enforced by | Test |
|---|---|---|---|
| **MH-I1** | **Hop 2 is unreachable until hop 1 produces a chain-proven `TerminalSettlementProof`.** | `buildAmmSwapHop` calls `verifyTerminalSettlementProof` as its first statement; `HOP2_READY` requires `settlementProof` **and** a positive `inputAmountRaw`; `BEGIN_HOP2` requires the proof again. | `MH 1.1`, `MH 1.2`, `MF MHF-1` (P1) |
| **MH-I2** | **A proof can only be minted from a terminal `CLAIMED` cross-layer session with authoritative evidence for every field.** | `mintTerminalSettlementProof` — the sole constructor — requires: terminal CLAIMED state, both authoritative verification stamps, `l1Verification.amountAuthoritative === true`, no `PROVIDER_ASSERTION` source, no recorded refund path, a matching claim tx id, an AUTHORITATIVE (never indexer) balance read, exact resource identity, a positive amount ≤ the accepted quote, receiving account == hop-2 account, satisfied confirmations, and fresh evidence. | `MH 2.1` (21 cases) |
| **MH-I3** | **A proof cannot be forged, mutated, or replayed.** | Module-private symbol brand (an object literal or JSON payload can never satisfy it); a fingerprint over the fact fields detects post-mint mutation; route binding, hop binding, recipient, resource, terminal status, and age are re-checked on every use. | `MH 1.1`, `MH 2.2`, `MF MHF-2`, `MF MHF-3` (20k tamper attempts) |
| **MH-I4** | **A settlement proof backs exactly ONE hop-2 execution.** | `proofConsumedByHop2` single-use binding, set on `BEGIN_HOP2` and checked on every further `BEGIN_HOP2`. | `MH 2.3`, `MF MHF-4` |
| **MH-I5** | **The intermediate TARI is never lost.** | `HOP1_SETTLED` requires a positive integer amount and a route-bound proof reference; a failed hop 2 pauses rather than failing the route; the settled amount is recorded on the record and the price model. | `MH 5.1`, `MF MHF-1` (P2) |
| **MH-I6** | **The final output never violates the user's accepted minimum.** | `buildAmmSwapHop` re-checks the refreshed `minOutput` against the accepted floor and returns `REQUOTE_REQUIRED` instead of lowering it; `HOP2_SETTLED` enforces the floor again in the state machine; `validateRouteRecord` refuses a route minimum below the accepted minimum. | `MH 4.2`, `MH 12.1`, `MF MHF-1` (P3) |
| **MH-I7** | **Slippage is applied exactly once per layer and is never doubled.** | Provider spread is applied inside `quoteXtmToTari`; AMM slippage inside `deriveMinOutput`; `buildRoutePrice` takes the **harder** of the AMM min and the user floor rather than composing them. | `MH 9.2` |
| **MH-I8** | **The AMM quote is always refreshed authoritatively after hop 1; it is never pre-signed or frozen at route-quote time.** | `AmmSwapHopInput` is only constructible post-settlement; `RouteHop.inputAmountRaw` is empty until a proof supplies it; `buildAmmSwapHop` performs a mandatory `resolveSwap` reread with a fresh `maxEpoch`. | `MH 4.1`, `MH 4.3` |
| **MH-I9** | **The AMM input is the ACTUAL settled amount, never the quote, cache, or advertisement.** | `buildAmmSwapHop` derives the input solely from `proof.resultingAmountRaw`. | `MH 4.1`, `MH 9.3` |
| **MH-I10** | **The AMM hop is structurally decoupled from cross-layer internals.** | `AmmSwapHopInput` has no field for a preimage, refund height, reservation, or script — the type system is the control, not a comment. | `MH 3.2` |
| **MH-I11** | **Resource identity is exact, and the only permitted intermediate is canonical TARI.** | `validateRouteRecord` requires the hop chain to match by exact address and the intermediate to be `isCanonicalTari` on `OOTLE_L2`; `buildAmmSwapHop` re-checks both legs; labels are never used for identity. | `MH 3.1` |
| **MH-I12** | **Settlement-to-execution identity is bound.** | The proof's `recipientAccount` must equal the hop-2 execution account at mint time and at every build. | `MH 8.2`, `MH 2.2` |
| **MH-I13** | **Terminal routes are terminal; a settled hop is never un-settled.** | Empty transition rows for `ROUTE_SETTLED`/`ROUTE_FAILED_TERMINAL`; no transition out of a settled hop. | `MH 7.1`, `MF MHF-1` (P4) |
| **MH-I14** | **UNKNOWN never authorises a blind resubmit.** | `HOP1_UNKNOWN`/`HOP2_UNKNOWN` → `ROUTE_RECOVERY_REQUIRED`, from which hop 2 is unreachable; `reconcileHop2` sets `resubmissionAllowed` only on a proven REJECTED/NOT_FOUND. | `MH 6.1`, `MF MHF-1` (P5) |
| **MH-I15** | **One route can never consume another route's settlement proof.** | `verifyTerminalSettlementProof(expected.routeId)`; `HOP1_SETTLED` requires `proofRef.routeId === routeId`. | `MH 2.3`, `MF MHF-2`, `MF MHF-1` (P6) |
| **MH-I16** | **Asset identity stays exact across every accepted transition.** | Asserted after every accepted transition in the fuzzer, plus `validateRouteRecord`. | `MF MHF-1` (P8) |
| **MH-I17** | **Amounts are raw BigInt integers everywhere, bounded at 2^128-1 and computed rather than typed.** | `requireRaw` in proof minting, `validateRouteRecord`, and every model builder; the bound is `(1n << 128n) - 1n`. | `MH 2.1`, `MH 14.1`, `MH 9.2` |
| **MH-I18** | **Partial completion is a first-class outcome, and the intermediate asset always remains user-controlled.** | `SKIP_HOP2` → `HOP2_SKIPPED` → `SETTLE_PARTIAL`; hop 2 stays `UNSETTLED`; `RouteRecoveryPolicy.intermediateAssetRemainsUserControlled` is a typed literal on every record. | `MH 5.2`, `MH 5.1` |
| **MH-I19** | **The developer trading fee is exactly zero, and fees stay separated.** | `buildRouteFees` returns `developerTradingFeeRaw: '0'`; `validateRouteRecord` refuses any other value. | `MH 9.1` |
| **MH-I20** | **Real submission stays OFF by default and mainnet stays refused.** | Inherited unchanged from the cross-layer gate. | `MH 12.2` |
| **MH-I21** | **The route result is inert by construction until settlement is provable.** | `RouteResult.composable` is typed `false`, `settlementStatus` starts `UNSETTLED`, `containsSecret` is `false`; the AMM hop is unreachable without a proof. | `XC 31.1`, `MH 11.1` |
